# TP Cuentas · descargas

Aquí solo están las versiones ya hechas de **TP Cuentas** (macOS 14 o posterior) y `version.json`, que es lo que consulta la app para saber si hay una versión nueva.

Para instalarla: baja el `.zip` de la última versión en *Releases*, descomprímelo y arrastra **TP Cuentas** a Aplicaciones. Las siguientes versiones se instalan solas desde la propia app.
